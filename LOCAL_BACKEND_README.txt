LOCAL BACKEND / ADMIN PANEL

1) Install Node.js if it is not installed.
2) Open this folder in Terminal / CMD.
3) Run: npm install
4) Run: npm start
5) Open Admin Panel: http://localhost:3000/admin.html
6) Open Website: http://localhost:3000/1.html

You can edit:
- Website text
- Footer details
- Contact phone/email/location
- Social links
- Gallery photos photo1-photo15
- Songs song1-song10
- Background image
- Profile/About image

No hosting needed. This works only on your local PC until you host it.
